# Stručný report

## 1. Cieľ práce

Cieľom práce bolo vytvoriť Python knižnicu na šifrovanie, dešifrovanie a kryptoanalýzu klasickej substitučnej šifry.

## 2. Použitá abeceda

Použitá bola abeceda:

```text
ABCDEFGHIJKLMNOPQRSTUVWXYZ_
```

Podtržítko `_` reprezentuje medzeru.

## 3. Implementácia šifrovania a dešifrovania

Doplňte opis:

- ako sa tvorí mapovanie `alphabet -> key`,
- ako sa tvorí inverzné mapovanie `key -> alphabet`,
- ako sa validuje kľúč.

## 4. Predspracovanie textu

Doplňte opis:

- odstránenie diakritiky,
- prevod na veľké písmená,
- náhrada medzier za `_`,
- odstránenie nepovolených znakov.

## 5. Referenčný jazykový model

Doplňte:

- zdroj českého textu,
- počet znakov po normalizácii,
- počet bigramov,
- ukážku najčastejších bigramov,
- spôsob vytvorenia relatívnej matice.

## 6. Metropolis-Hastings algoritmus

Doplňte:

- počet iterácií,
- spôsob inicializácie kľúča,
- spôsob generovania kandidátneho kľúča,
- akceptačné pravidlo,
- spôsob výberu najlepšieho kľúča.
