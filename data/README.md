# Dáta

## `raw/`

Sem patrí dlhý český referenčný text, napríklad kniha z Wikisource.

Príklad:

```text
data/raw/krakatit.txt
```

## `reference/`

Sem sa uloží referenčná relatívna bigramová matica.

Príklad:

```text
data/reference/TM_ref.csv
```

## `ciphertexts/`

Sem patria zašifrované texty od vyučujúceho.

Príklad:

```text
data/ciphertexts/text_1000_sample_20_ciphertext.txt
```
